PG

Pada data latih kategori pekerjaan orang tua = "Nelayan" tidak pernah muncul pada kelompok mahasiswa penerima beasiswa ($n_{\text{Nelayan}, \text{Ya}} = 0$), padahal total penerima beasiswa $n_{\text{Ya}} = 100$. Pembahasan Mendalam:
Rumus Laplace Smoothing untuk fitur kategorik dengan $K$ level: $$P(X = x \mid Y = c) = \frac{n_{xc} + \alpha}{n_c + \alpha \cdot K}$$ Dengan $\alpha = 1$, $n_{\text{Nelayan}, \text{Ya}} = 0$, $n_{\text{Ya}} = 100$, dan $K = 5$: $$P = \frac{0 + 1}{100 + 1 \times 5} = \frac{1}{105} \approx 0{,}0095$$ Hal ini mencegah peluang posterior menjadi nol mutlak (zero-probability problem) yang akan melumpuhkan perkalian Naive Bayes.

Kunci Jawaban: A

Soal 11. (JST - Saturasi Gradien FFNN)
PG Bobot Tinggi
Dalam arsitektur Feed-Forward Neural Network (FFNN), fungsi aktivasi sigmoid $\sigma(z) = \frac{1}{1 + e^{-z}}$ memiliki turunan analitis $\sigma'(z) = \sigma(z)(1 - \sigma(z))$. Nilai maksimum dari turunan $\sigma'(z)$ ini adalah...
Kunci Jawaban: B
Pembahasan Mendalam:
Fungsi $\sigma'(z) = \sigma(z)(1 - \sigma(z))$. Misalkan $u = \sigma(z) \in (0, 1)$.
Fungsi kuadrat $f(u) = u(1 - u) = u - u^2$ mencapai nilai puncak ketika turunannya terhadap $u$ bernilai nol: $$f'(u) = 1 - 2u = 0 \implies u = 0{,}5$$ Ketika $u = \sigma(z) = 0{,}5$, terjadi pada $z = 0$.
Nilai puncak turunan: $f(0{,}5) = 0{,}5 \times (1 - 0{,}5) = \mathbf{0{,}25}$.
Implikasi UAS: Karena nilai turunan maksimal hanya $0{,}25$, ketika sinyal gradien dikalikan berulang mundur melalui banyak lapisan tersembunyi ($0{,}25 \times 0{,}25 \times \dots$), nilai gradien akan menyusut mendekati nol (*vanishing gradient*).

Soal 17. (Association Rule - Support, Conf, Lift)
PG Bobot Tinggi
Dari 10.000 transaksi di sebuah supermarket, tercatat: • 2.000 transaksi memuat Roti.
• 1.500 transaksi memuat Selai.
• 600 transaksi memuat Roti dan Selai secara bersamaan.
Berapakah nilai Support, Confidence, dan Lift dari aturan asosiasi: $\text{Roti} \Rightarrow \text{Selai}$?
Kunci Jawaban: B
Pembahasan Mendalam:
$N = 10.000$.
• $\text{Supp}(\text{Roti}) = \frac{2.000}{10.000} = 0{,}20$.
• $\text{Supp}(\text{Selai}) = \frac{1.500}{10.000} = 0{,}15$.
• $\text{Supp}(\text{Roti} \cap \text{Selai}) = \frac{600}{10.000} = \mathbf{0{,}06}$ (6%).
• $\text{Confidence}(\text{Roti} \Rightarrow \text{Selai}) = \frac{\text{Supp}(\text{Roti} \cap \text{Selai})}{\text{Supp}(\text{Roti})} = \frac{0{,}06}{0{,}20} = \mathbf{0{,}30}$ (30%).
• $\text{Lift}(\text{Roti} \Rightarrow \text{Selai}) = \frac{\text{Confidence}}{\text{Supp}(\text{Selai})} = \frac{0{,}30}{0{,}15} = \mathbf{2{,}00}$.
Karena $\text{Lift} = 2{,}00 > 1$, konsumen yang membeli Roti memiliki kecenderungan membeli Selai 2 kali lebih besar dibandingkan probabilitas pembelian Selai secara acak di populasi.

Output Gate ($o_t$): $$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$ Menentukan bagian mana dari cell state yang akan dikeluarkan menjadi output prediksi.
b. Pembaruan State
• Pembaruan Cell State ($C_t$): $$C_t = f_t * C_{t-1} + i_t * \tilde{C}_t$$ Operasi $*$ adalah perkalian elemen-per-elemen (Hadamard product). Jalur ini berfungsi seperti "jalan tol linier" bebas hambatan yang memungkinkan gradien mengalir tanpa lenyap (*solving vanishing gradient*).
• Pembaruan Hidden State ($h_t$): $$h_t = o_t * \tanh(C_t)$$ Fungsi $\tanh$ menormalkan nilai memori sel kembali ke rentang $[-1, 1]$ sebelum difilter oleh gerbang keluaran $o_t$.
c. Data Leakage & Pembagian Kronologis
• Data Leakage (Kebocoran Masa Depan): Terjadi jika data deret waktu dibagi secara acak (random split). Titik waktu $t+1$ masuk data latih sementara titik $t$ masuk data uji. Model akan "mencontek" masa depan untuk menebak masa lalu, menghasilkan metrik akurasi latih yang tinggi semu tetapi gagal total saat diterapkan di masa depan nyata.
• Solusi yang Sah: Pembagian Kronologis Wajib: Misal 80% periode awal (bulan 1–96) dialokasikan sebagai data latih, dan 20% periode akhir (bulan 97–120) dialokasikan sebagai data uji.
