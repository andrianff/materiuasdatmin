Association Rule — Apriori

Market basket analysis · dicetus Agrawal dkk 1993

Konsep dasar

  • Cari aturan asosiatif "if … then …" antar item
  • 2 tahap: ① frequent pattern → ② bentuk rule
  • Syarat: min support & min confidence
Contoh: {roti,mentega}→{susu} (sup 40%, conf 50%)
= 50% yg beli roti+mentega juga beli susu

Rumus

$$\text{Sup}(A)=\frac{\#\text{trx memuat }A}{\#\text{total trx}}\qquad \text{Sup}(A\cap B)=\frac{\#(A\text{ dan }B)}{\#\text{total}}$$ $$\text{Conf}(A\to B)=P(B|A)=\frac{\#(A\text{ dan }B)}{\#A}$$

Conf tidak simetris, support simetris.

Istilah

  • $I$ = semua item; $D$ = semua transaksi
  • $k$-itemset = itemset isi $k$ item
  • Frekuensi itemset = # trx memuat itemset
  • Frequent = frekuensi $\ge\Phi$ ; $F_k$ = himp. frequent $k$-item
  • Antecedent (if) boleh >1 ; Consequent (then) hanya 1

Langkah Apriori

  1. Tentukan $\Phi$
  2. Cari semua frequent itemset ($F_1,F_2,\dots$ sampai kosong)
  3. Tiap frequent itemset: ambil 1 unsur $s$; rule if $(ss-s)$ then $s$
  4. Hitung sup & conf → pilih conf ≥ min
  5. Pilih sup × conf terbesar
Prinsip Apriori: Z bukan frequent ⇒ $Z\cup A$ pasti bukan frequent.
Join: itemset dg item awal sama, mis. {A,B}+{A,F}→{A,B,F}

hal 2

FP-Tree & FP-Growth

Kenapa?

  • Apriori: scan DB berulang → bottleneck, banyak kandidat
  • FP-Tree (Zhao et al. 2003): data dimampatkan jadi pohon, tanpa candidate generation

Isi FP-Tree

  • Root 'null' + subtree + tabel frequent header
  • Tiap node: label item, support count, pointer (putus-putus ke node berlabel sama)
  • Best: 1 path · Worst: = data asli (+ pointer)
  • Urut support menurun = heuristik

Bangun FP-Tree (min count 2)

  1. Scan → hitung support tiap item
  2. Buang item < min (f,r,z,g,h)
  3. Urutkan tiap trx: frekuensi ↓ (a8 b7 c6 d5 e3)
  4. Masukkan trx satu-satu: prefix sama → count+1, beda → cabang baru (count 1)
  5. Hubungkan node sama label (link)
Walau b muncul di T1 & T2, path disjoint karena prefix beda!
hal 3

FP-Growth

  • Bottom-up (leaf → root), divide & conquer, rekursif
  • Suffix: e → de, ce, be, ae → … lalu d → cd … dst

3 Tugas Utama

  1. Conditional Pattern Base = prefix path + suffix pattern
  2. Conditional FP-Tree: jumlahkan count per item di base; buang yg < min
  3. Cari frequent itemset: single path → kombinasi item; bukan → FP-Growth rekursif

Cond. FP-Tree untuk e (min 2)

  1. Jumlah count e = 1+1+1 = 3 ≥ 2 → {e} frequent
  2. Update count prefix path jd # trx yg memuat e (a=2, b=1, c=1)
  3. Hapus node e
  4. Buang item tak sering: b = 1 < 2 → buang (be ✗). c=2, d=2 tetap
  5. Rekursif: de (→ ade), ce, ae

Latihan FP-Growth: item Grape (min sup = 4)

  1. Count: Cheese 9, Bread 5, Egg 5, Grape 5, Orange 4, Apple 3, Milk 2 → buang Apple, Milk
  2. Urutan: Cheese, Bread, Egg, Grape, Orange
  3. Prefix path ke Grape (cond. pattern base):
    {Ch,Br}:1 · {Ch}:1 · {Ch,Eg}:1 · {Ch,Br,Eg}:1 · {Ch,Br}:1
  4. Count di base: Cheese 5, Bread 3, Egg 2 → hanya Cheese ≥ 4
  5. Cond. FP-tree Grape: null → Cheese:5 (single path)
Hasil: {Grape}:5 dan {Cheese, Grape}:5
